# SiteVoice 0.2.0 검증 기록

2026-11-21 · Apple Silicon macOS 26.7.1

- 타입 검사와 단위·통합 테스트 34개 통과. 테마 및 업데이트 설정 기본값과 기존 설정 호환을 확인했다.
- Electron E2E 3개 통과. SiteVoice 창 제목, 설정 창과 녹음 표시창의 테마 적용, 테마와 시작 시 업데이트 확인 설정의 재시작 후 복원, 암호화된 API 키의 재시작 후 복원을 검증했다. 녹음과 결과 흐름은 가상 마이크와 모의 API로 확인했다.
- 업데이터의 모의 테스트는 업데이트 없음, 사용자 거부·승인, 중복 시도와 작업 중 설치 방지, 미설정 피드를 확인했다. 설치 전 승인 정책은 실제 배포 서버나 인증서 없이 모의로 검증했다.
- Apple Silicon 앱과 내장 보조 프로그램의 로컬 서명 및 DMG 체크섬을 검증했다. 이 설치본에는 업데이트 피드가 없으며 Apple 공증을 하지 않았다.
- `npm audit --omit=dev`에서 취약점 0건. 전체 감사에서 패키징 도구의 간접 의존성에 중간 등급 진단 6건이 남았다.
