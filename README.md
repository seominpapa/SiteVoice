# SiteVoice

다른 앱에서 단축키를 눌러 말을 받아쓰고, 번복과 반복, 군더더기만 정리해 원래 입력 칸에 붙여넣는 한국어 데스크톱 앱입니다. **받아쓴 결과**에는 녹음한 날짜·시간과 실제로 입력하거나 복사할 문장만 표시합니다. 번역이나 내용 축약은 하지 않습니다.

## 다운로드

| 운영체제 | 설치 파일 | 설치 방법 |
| --- | --- | --- |
| Mac · Apple Silicon | [Mac용 DMG 다운로드 (0.2.9)](https://github.com/seominpapa/SiteVoice/releases/download/v0.2.9/SiteVoice-0.2.9-mac-arm64.dmg) | DMG를 열고 SiteVoice를 응용 프로그램 폴더에 옮깁니다. |
| Windows · x64 | [Windows용 EXE 다운로드 (0.2.7)](https://github.com/seominpapa/SiteVoice/releases/download/v0.2.7/SiteVoice-0.2.7-win-x64.exe) | EXE를 실행하고 설치 안내를 따릅니다. |

[GitHub 릴리스 목록](https://github.com/seominpapa/SiteVoice/releases)에서 다른 버전도 확인할 수 있습니다. 이 저장소는 비공개이므로 접근 권한이 있는 GitHub 계정으로 로그인해야 내려받을 수 있습니다. Windows 설치 파일에는 디지털 서명이 없습니다.

## 데스크톱 앱으로 만든 이유

브라우저에서도 페이지 안에서 녹음하고, 음성을 글로 바꾼 뒤 복사할 수 있습니다. 하지만 다른 앱을 쓰는 동안 `Fn`이나 Windows 로고 키를 전역 단축키로 감지하거나, 그 앱의 입력 칸을 확인해 커서 위치에 자동으로 붙여넣는 기능은 브라우저만으로 제공할 수 없습니다. SiteVoice는 이 기능에 운영체제의 기능을 사용하는 데스크톱 앱입니다. 브라우저용 빌드나 `.command` 실행 파일은 제공하지 않습니다.

## 시작하기

1. **시작하기**에서 개인 OpenAI API 키를 저장하고 **키 확인**을 누릅니다. 키 확인은 설정된 두 모델의 정보 조회만 실행합니다. 계정의 모델 실행 권한과 잔액은 실제 요청 시 별도로 적용됩니다.
2. 아래의 운영체제별 권한을 확인한 뒤 앱의 **마이크 테스트**로 입력 신호를 확인합니다.
3. 외부 앱의 텍스트 입력 칸에 커서를 둔 뒤 **Mac 왼쪽 Fn(🌐) / Windows 로고 키**를 단독으로 짧게 눌렀다 떼어 녹음합니다. 같은 키를 한 번 더 눌렀다 떼면 녹음이 끝납니다. 표시창에서 종료하거나 취소할 수도 있습니다.
4. 원래 입력 칸을 확인할 수 없거나 자동 붙여넣기가 보류되면, 녹음 표시창 자리에 문장과 **파란색 복사 아이콘**이 나타납니다. 복사가 완료되면 표시창이 자동으로 닫힙니다. 원하는 곳에 직접 붙여넣으세요. 앱이 “붙여넣기 키를 보냈습니다”라고 표시하면 실제로 문장이 들어갔는지 입력 칸에서 확인하세요.

처음 사용하는 앱은 TextEdit 또는 메모장의 빈 문서로 확인하세요. 암호 입력 칸, 범위가 선택된 입력 칸, 조회가 제한된 편집기, Windows에서 관리자 권한으로 실행된 앱은 자동 입력이 제한될 수 있습니다. 자동으로 Enter나 전송을 누르지 않습니다.

**환경 설정 → 모델과 단축키 → 단축키 입력**에서 원하는 키나 조합을 직접 누르고 **환경 설정 저장**으로 적용합니다. Esc로 입력을 취소하고, **기본값 사용**으로 되돌릴 수 있습니다. 기존 버전에서 지정한 다른 단축키는 유지됩니다.

**환경 설정 → 모델과 단축키 → 음성 전사 모델**에서 녹음 후 전사와 실시간 전사 중 하나를 고른 뒤 **환경 설정 저장**을 누르세요.

| 전사 모드 | 음성을 보내는 시점 |
| --- | --- |
| 실시간 전사 (`gpt-live-transcribe`, 기본값) | 녹음하는 동안 음성을 OpenAI로 보냅니다. 전사 지연은 속도와 정확도의 균형을 잡는 `medium`을 사용합니다. 실시간 전사에 실패하면 같은 녹음을 `gpt-transcribe`에 파일로 다시 보내므로 다시 말할 필요는 없습니다. |
| 녹음 후 전사 (`gpt-transcribe`) | 녹음을 마친 뒤 음성 파일을 OpenAI로 보냅니다. |

두 모드 모두 녹음이 끝난 뒤 정리한 문장을 보여 줍니다. 기존에 저장된 전사 모델은 유지됩니다. 실시간 전사로 바꾸려면 드롭다운에서 선택한 뒤 저장하세요. 문장 정리 모델(기본값 `gpt-6-luna`)은 따로 설정할 수 있습니다. 정리 단계에서는 “첫째, 둘째”처럼 항목을 분명히 나열한 말을 번호 목록으로 정리하고, “화요일, 아니 수요일”처럼 명확하게 바로잡은 부분은 최종 표현으로 남깁니다. 수정 의도가 불분명하면 원래 표현을 유지합니다.

**개인 용어 사전**에는 **용어**와 **뜻·사용 맥락**을 입력하고 **용어 추가 → 환경 설정 저장**을 누르세요. 예를 들어 용어에 `숏크리트`, 뜻에는 `터널이나 사면 표면에 뿜어 붙이는 콘크리트`를 적을 수 있습니다. 기존에 저장한 용어는 그대로 유지되고, 뜻은 나중에 채울 수 있습니다.

전사 모델에는 가능한 경우 용어의 표기를 힌트로 보냅니다. 문장 정리 모델은 용어와 뜻을 함께 받아, 발화에서 같은 대상을 가리킬 때만 참고합니다. 자동 치환하거나 말하지 않은 설명을 결과에 덧붙이는 기능은 아닙니다.

**화면 테마**에서 밝게 또는 어둡게를 선택할 수 있습니다. 선택은 즉시 적용되며 다음 실행에도 유지됩니다.

**결과 → 받아쓴 결과**에서 지난 문장을 최신순으로 확인하고, 각 문장 옆 **결과 복사**로 다시 복사할 수 있습니다. 표시창에서 복사하거나 앱을 완전히 종료해도 저장된 기록은 남습니다. 같은 OS 계정에서 앱을 업데이트한 뒤에도 열 수 있습니다.

**결과 → 최근 받아쓰기 진단**을 펼치면 마지막으로 정리까지 끝난 받아쓰기에 사용된 전사 모델, 녹음 시작부터 종료까지의 시간, 종료부터 전사가 끝날 때까지의 시간, 문장 정리 시간을 확인할 수 있습니다. 실시간 연결이 실패해 파일로 다시 전사한 경우도 표시합니다. 진단은 앱을 종료하면 사라지고, 받아쓰기 기록에는 남지 않습니다.

창을 닫으면 메뉴 막대/트레이에 남습니다. **완전히 종료**를 누르면 진행 중인 녹음은 중단됩니다. 자동 시작은 켜지지 않습니다.

## 처음 설치할 때 필요한 권한

**macOS**에서는 응용 프로그램 폴더에 설치한 `SiteVoice.app`을 기준으로 설정합니다.

1. **마이크:** **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 SiteVoice를 켭니다.
2. **손쉬운 사용:** 다른 앱에 자동으로 붙여넣으려면 SiteVoice에서 **손쉬운 사용 설정 열기**를 누른 뒤 SiteVoice를 켭니다.
3. **입력 모니터링:** Mac에서 Fn 단독 입력이 감지되지 않으면 **환경 설정 → 모델과 단축키 → 입력 모니터링 설정 열기**에서 SiteVoice를 켭니다. 일반 키 조합은 이 권한 없이도 설정할 수 있습니다.
4. 처음 설정할 때 목록에 SiteVoice가 없으면 왼쪽 아래 **+**에서 **응용 프로그램 → SiteVoice.app**을 추가하고 스위치를 켭니다. 권한을 바꾼 뒤 앱에서 **완전히 종료**를 누르고 다시 엽니다.
5. **Fn을 누를 때 이모지 창이 같이 뜨면** SiteVoice의 **키보드 설정 열기**를 누르고 **🌐 키를 누를 때 실행할 동작 → 안 함**을 선택하세요. macOS 버전에 따라 **fn 키 → 동작 없음**으로 표시될 수 있습니다. **Control + Command + Space**로도 이모지를 열 수 있습니다.

### Windows

Windows에는 SiteVoice를 손쉬운 사용이나 입력 모니터링 목록에 등록하거나 업데이트 후 다시 등록하는 절차가 없습니다. 마이크가 차단되어 있으면 **설정 → 개인 정보 및 보안 → 마이크**에서 **마이크 액세스**, **앱에서 마이크에 액세스하도록 허용**, **데스크톱 앱에서 마이크에 액세스하도록 허용**을 켜세요. Windows 10에서는 **설정 → 개인 정보 → 마이크**에 있습니다. 관리자 권한으로 열린 프로그램처럼 Windows가 입력을 제한하는 곳에는 자동 붙여넣기 대신 복사 아이콘을 사용하세요. Windows 로고 키 단독 탭을 SiteVoice에서 쓰더라도 Win+E 같은 조합은 유지됩니다.

공식 안내: [Apple 손쉬운 사용](https://support.apple.com/ko-kr/guide/mac-help/mh43185/mac), [Apple 입력 모니터링](https://support.apple.com/ko-kr/guide/mac-help/mchl4cedafb6/mac), [Apple 코드 서명 요구사항](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements), [Microsoft 마이크 권한](https://support.microsoft.com/en-us/windows/privacy/turn-on-app-permissions-for-your-microphone-in-windows).

## 저장과 전달

API 키는 Main에서만 읽으며 Electron의 비동기 `safeStorage`로 암호화합니다. 설정 파일에는 모델, 단축키, 마이크 ID, 용어 사전과 화면 설정 등이 남습니다. 받아쓰기 기록은 녹음 시각, 정리된 문장, 필요한 경우 검토 안내만 OS 보안 저장소로 암호화해 이 컴퓨터에 보관합니다. 보안 저장소를 사용할 수 없으면 앱에서 저장할 수 없다고 알립니다. 원문과 음성 파일은 저장하지 않습니다. 음성, 전사문, 용어 사전은 전사·문장 정리를 위해 OpenAI에 전송됩니다. 받아쓰기 기능에는 별도 서버, 계정 로그인, 기록 동기화, 텔레메트리가 없습니다.

숫자·단위·부정 표현의 눈에 띄는 변경은 자동 입력을 보류합니다. 이 검사는 제한된 안전장치이며, 모든 이름·조건·의미 변화를 찾아내지는 못합니다. 정확한 수치가 중요한 문장은 붙여넣기 전에 확인하세요.

## 개발 및 패키징

Node.js 24.13 이상 및 npm이 필요합니다. macOS에서는 Xcode Command Line Tools의 Swift 컴파일러를, Windows에서는 Visual Studio Build Tools의 **Desktop development with C++**와 Windows SDK를 준비하고 **x64 Native Tools Command Prompt**에서 실행하세요.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run test:coverage
npm run test:e2e
```

Electron E2E는 실행 중인 데스크톱 세션을 사용합니다. 임시 프로필, 가상 마이크, 모의 API만 사용합니다. 유효한 API 키나 실제 녹음은 필요하지 않습니다.

| 명령 | 환경 | 결과 |
| --- | --- | --- |
| `npm run package:mac` | macOS 13+ | Apple Silicon `.app`, `.dmg` |
| `npm run package:mac:intel` | macOS 14+ 대상 | Intel `.app`, `.dmg` |
| `npm run package:win` | Windows x64 + MSVC | NSIS `.exe` |

산출물은 `release/`에 생성됩니다. macOS 개발 빌드는 로컬 서명(ad hoc)만 적용하며 Apple 공증을 하지 않습니다. 배포용은 Developer ID와 공증 설정을 갖추고 `VOICEINPUT_SIGNING=1`로 빌드하세요. 패키징은 원격 게시를 실행하지 않습니다.

## 업데이트

**환경 설정 → 앱 업데이트**에서 시작 시 자동 확인을 켜거나 끌 수 있습니다. 자동 확인을 켜면 다음 실행 때 새 버전을 확인합니다. 새 버전이 있을 때만 설치 여부를 묻고, **업데이트 설치**를 선택한 경우 내려받아 적용합니다.

SiteVoice의 Apple Silicon 배포본은 비공개 GitHub 릴리스에서 업데이트를 받습니다. 이 기능을 사용하려면 해당 저장소에 접근할 수 있는 계정으로 이 Mac의 GitHub CLI(`gh`)에 로그인해 두세요. 업데이트 기능이 없던 이전 설치본은 새 설치본으로 한 번 교체해야 합니다. 업데이트할 때는 응용 프로그램 폴더에 설치한 SiteVoice를 사용하세요.

Windows에서는 새 버전의 EXE를 GitHub 릴리스에서 내려받아 설치합니다.

이 저장소의 Apple Silicon 배포 파일은 아래 명령으로 만듭니다. Apple 공증 프로필과 같은 Apple 개발자 팀의 Developer ID Application 인증서가 필요합니다. 생성된 `latest-mac.yml`, ZIP·DMG와 관련 블록맵은 같은 GitHub 릴리스에 올립니다.

```sh
VOICEINPUT_SIGNING=1 VOICEINPUT_GITHUB_UPDATES=1 APPLE_KEYCHAIN_PROFILE=SiteVoiceNotary npm run package:mac
```

별도 배포 환경에서는 `VOICEINPUT_UPDATE_URL`로 HTTPS 업데이트 피드를 지정할 수도 있습니다. 일반 개발 빌드는 업데이트 피드에 연결하지 않습니다.

## 확인 범위

- 단위 및 통합 테스트는 모의 API 요청, 상태 전이, 취소 후 늦은 응답, 전사 원문 보존, API 키 저장, IPC, 오디오 수집을 확인합니다.
- Electron 자동화는 macOS에서 테스트 키가 앱 재시작 뒤에도 읽히는지와 가상 녹음부터 결과까지를 확인합니다. 이 테스트는 실제 마이크·접근성·외부 앱 붙여넣기 검증을 대신하지 않습니다.
- 실기기 검증은 Mac의 TextEdit, Windows의 메모장에서 각각 시행합니다. (1) 권한 허용 후 마이크와 전역 키로 녹음하고 커서 위치에 결과가 들어가는지, (2) 처리 중 다른 입력 칸으로 이동하거나 영역을 선택하면 복사로 전환되는지, (3) 작업 취소/마이크 분리/절전 후 뒤늦게 붙여넣지 않는지, (4) 클립보드 내용을 그대로 보존하는지, (5) 창 닫기/트레이 완전 종료/재실행을 확인합니다. Windows는 NSIS 설치 및 제거도 확인합니다.

구성: `src/main/`은 OS·키·IPC 관리, `src/core/`는 전사와 정리, `src/renderer/`는 한국어 화면과 녹음, `native/`는 macOS AX/Quartz 및 Windows UI Automation/SendInput 보조 프로그램입니다. 디자인은 제공된 DJI 분석 자료의 흰색·회색 표면, 얇은 구분선, 파란색 버튼을 참고했습니다. 밝은 테마와 차콜 배경의 어두운 테마를 제공합니다.
